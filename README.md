# Roamly Travel Website

A modern travel-themed website with enhanced visuals, brand identity, richer trip tools, and complete client-side auth/booking flows.

## What's included

- Custom **Roamly Travel logo** (`logo.svg`) used in header, footer, and favicon
- Rich travel UI with hero imagery, destination gallery, featured experiences, facilities, FAQ, planner, and package catalog
- More pictures and visual cards across the site
- Package search + sorting (budget/type/price/rating)
- Saved trips (favorites) panel
- Itinerary planner generator
- Authentication (Sign Up / Login / Logout) with localStorage persistence
- Protected booking flow with traveler count, promo code (`ROAM10`), and total calculation
- Newsletter subscription
- Dark mode toggle with persisted preference
- Responsive layout with mobile menu

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.
